Hello there,

if you would like to know how stuf actualy works, how to build it yourself, write code, build websites, train AI models, Configurenetworks, and so much more.
Then take a look at ELECTRONICS-ICT at the university college VIVES.

 
 
 
 

Electronics

Learn about electronic components, design
circuits and develop pcb's. You can develop your
own IoT-devices, use microcontrollers and work
with sensors and actuators. Knowing how stuff
really works and build future innovative stuff.

Networks

Learn about internet/networks protocols. Build,
configure and maintain company networks.
Setup and maintain servers. Run several services
in docker containers. And all this while keeping
things secure.

Software & AI

Learn to program in several languages in a object
oriented way. Build stand alone applications, web
and mobile apps and firmware for
microcontrollers. Learn the basics of AI and how
to implement a model on a microcontroller.
